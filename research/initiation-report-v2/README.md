# initiation-report-v2

v2 of the IPO Radar initiation report — an 11-page Goldman/Citi-style
research report rendered from a single JSON brief.

- `schema.md` — JSON schema the renderer consumes
- `extraction-prompt.md` — Claude prompt that produces the JSON from an S-1
- `render_html.py` — dark Velocia HTML renderer
- `render_pdf.py` — white-bg IB-style PDF renderer
- `sample-helion.json` / `sample-helion.pdf` — illustrative sample
- `cerebras.json` / `cerebras.html` / `cerebras-systems.pdf` — real-S1 sample
- `hero.png` / `img-*.png` — cover hero + body images for the Cerebras sample
